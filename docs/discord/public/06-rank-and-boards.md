📈 **Step 5 — Rank & leaderboards**

Your strength is shown as **ki**.
• New players start near **1000**
• Win → ki usually goes up
• Lose → ki usually goes down
• Big upsets move ki more
• The bot tracks **overall** skill and skill **per hero**

**See a profile**
```
/rank
/rank user:@Friend
/rank nick:SomeNick
```

**Leaderboards**
```
/leaderboard show
/leaderboard show page:2
/leaderboard heroes
/leaderboard hero name:Goku
```

Some servers also have a **live leaderboard** message that updates after matches.

Some leagues offer a full rank reset when staff enable it:
```
/rank_reset
```
Resets your overall and hero ki for that league. A cooldown applies between self-resets. You cannot reset while you are in an active lobby or match.

Remember: ki is a score, not a trophy case. Play, learn, climb.
